# Ultra-Smart Table & Ledger Workspace Architecture Prompt

## 1. Core Philosophy: Reading Comfort First & Zero Visual Clutter
- **Prioritize Reading Comfort:** Make reading records, quotas, statuses, and ledger tables effortless, spacious, and visually calm.
- **Hide Rarely-Used Formatting/Action Bars by Default:** Move heavy formatting, bulk editing, export/audit/header-customization controls, and rarely needed settings out of the main reading flow into a dedicated **Ledger Actions Menu / Drawer** or triggered on demand—keeping the main screen focused on clean reading.
- **Non-Destructive Guarantee:** Keep **100% of existing features, filters, search, selection actions, audit tools, exports, edit options, and data intact**. Nothing is deleted; access is simply made smarter, cleaner, and contextual.

## 2. Smart Editor Actions ("إجراءات المحرر") Visibility Rules
- Do **NOT** keep the `إجراءات المحرر` (delete/edit icons) column permanently visible as visual noise during normal reading.
- Show editor/row actions **only** when:
  1. **Editor Mode (`وضع المحرر`)** is explicitly turned on, OR
  2. The user **taps/selects a row/name** (surfacing quick row actions/options cleanly), OR
  3. **Multi-selection (`تحديد`)** is active (surfacing batch/selection actions cleanly as part of the selection toolbar).

## 3. Pro "Viewing Mode" (`وضع المشاهدة`) + Auto-Lock Protection (`وضع القفل الذكي`)
- Create a dedicated, ultra-smart **Viewing Mode (`وضع المشاهدة`)** designed purely for distraction-free, comfortable table inspection:
  - Hides distracting top/bottom chrome or non-essential surrounding controls so **the table takes center stage** cleanly.
  - **Top Header in Viewing Mode:** Sleek, compact, and smart, featuring:
    - **Collapsible / On-Demand Search** (expands cleanly when tapped; stays tucked away otherwise).
    - **Right-Side Hamburger Menu (`☰`)** dedicated to **Table Options & Controls** (sorting, filtering, column visibility, lock toggle, exit viewing mode, quick table actions).
    - **Smart Lock State (`وضع القفل`):** Enabled **automatically** in Viewing Mode so accidental taps on rows, cells, or controls inside the table do not trigger unwanted edits or accidental actions while scrolling/reading.
    - **Quick Unlock Toggle in the Top Bar:** A clear, instant lock/unlock control right in the top bar so the user can unlock with one tap whenever they want to select a name, edit, or apply an action/tool.

## 4. Smart, Customizable Attached Table Header Field ("رأس الجدول الذكي المتصل")
- Above each table, integrate a **smart, compact, customizable header strip/field that seamlessly merges with the top of the table** as its unified, intelligent table header.
- **Supported Metadata & Custom Sub-Sections:**
  - Table title / name
  - Parent Agency (`الوكالة`) & Agency Number (`رقم الوكالة`)
  - Quota Number (`رقم الحصة`) & Date (`التاريخ`)
  - Custom main titles and **addable/customizable sub-title sections (`عناوين فرعية قابلة للإضافة والتخصيص`)** (e.g., notes, cycle/period, governorate/district, or any custom label the user adds).
- **Deep Yet Clean Customization:** Allow deep customization of which fields appear, their order, sub-sections, and visual styling, while keeping the default appearance compact, sleek, and naturally fused to the table without clutter.

## 5. Living Motion, Smart Micro-Interactions & Alive Themes
- Infuse the tables, headers, drawers, locks, and transitions with **alive, intelligent motion**:
  - Smooth state transitions when entering/exiting Viewing Mode, toggling Lock/Unlock, opening row/selection actions, or expanding search.
  - Alive, responsive icons and tactile feedback (subtle lock/unlock spring motion, smooth row highlight, fluid drawer slide) that feel organic and refined—never jarring or heavy.
  - Support **living themes / dynamic visual skins** that harmonize seamlessly with the active app theme and full Arabic RTL (`dir="rtl"`) layout.

## 6. Execution Steps
1. Audit the current Ledger/Table screen, top/bottom bars, `إجراءات المحرر`, selection bar, header metadata block, and theme/motion system without removing any features.
2. Hide `إجراءات المحرر` by default and reveal row/selection/editor actions contextually.
3. Build **Viewing Mode (`وضع المشاهدة`)** with auto-lock (`وضع القفل`), one-tap unlock in the top bar, on-demand search, and the right-side Table Hamburger Menu.
4. Build the **Smart Attached Table Header** above tables with agency/number/quota/date/custom sub-sections and deep customization.
5. Polish with living motion, theme harmony, and responsive RTL support across mobile and desktop.
